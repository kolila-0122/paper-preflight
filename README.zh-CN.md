# paper-preflight

投稿前自查工具。抓的是**会在技术审查被退回**的那类问题：图号引用顺序对不上、缩写先用后定义、同一个指标两处数值不同；顺带量一下文字离已发表论文有多远。

[English](README.md) | 简体中文

## 三层，各管各的

| 层 | 跑什么 | 抓什么 |
|---|---|---|
| **L1 一致性** | `semantic_audit.py` | 图号引用顺序 / 缺图注、同名指标数值冲突、缩写先用后定义、近重复句、反复起句、局限段与正文相抵 |
| **L2 文体** | `style_audit.py` | 句长分布、连接词密度与种类、模糊限制语 |
| **L3 语义** | `references/protocol.md` | 结论超出证据、跨节矛盾、术语混用——**是流程，不是脚本** |

分开是有意的：脚本判断不了"这句话科学上错了"。假装能判断，比不判断更糟。

## 用法

不需要安装，Python 3.9+ 标准库即可。只有读 `.docx` 才需要 `pip install python-docx`。

```bash
# L1：有高风险时退出码为 1，可接 CI
python scripts/semantic_audit.py --file 稿件.md --out 报告_L1.md

# L2：对照 assets/baseline.json
python scripts/style_audit.py --file 稿件.md --out 报告_L2.md
```

`.docx` 可直接传入，图注与表格一并读取。

## 示例

`examples/demo_manuscript.md` 是一篇**故意埋了 6 个缺陷**的短文。跑 L1：

```
命中 6 条（高 2 / 中 4 / 低 0）
  高  同名指标数值冲突      number_conflict       4.2 vs 6.1 %
  高  有图注但正文未引用    fig_legend_not_cited  Fig. 2
  中  图号引用顺序错乱      fig_out_of_order      [3, 1]
  中  缩写首次出现未定义    abbr_undefined        PFS
  中  近重复句              near_duplicate        ratio 0.85
  中  同一句式反复起句      repeated_opener       "the score was" ×4
```

## 最该看的四项

**图号顺序。** 期刊要求按首次引用顺序编号。每加一张图就要重排一次，而重排最容易漏——这个错误任何词级检查都发现不了，却能让你白等一轮审稿。

**数值冲突。** 同一个量在两处写成不同值，通常是改了一处忘了另一处。

**缩写先用后定义。** 缩略语表里有，但正文二十页前就用了。对编辑算"已定义"，对读者不算。

**反复起句。** `We therefore repeated …` 连开六句。连接词**密度**完全正常，人读到第二句就发现了。

## 文体基线

`assets/baseline.json` 来自 16 篇开放获取全文（5,715 句），**用与检查脚本相同的分句器**统计，可直接比较：

| 指标 | 基线 | 建议 |
|---|---:|---|
| 平均句长 | 21.9 词 | 20–23 |
| ≥35 词句占比 | 9.9% | ≤12% |
| ≤15 词句占比 | 31.5% | 28–33% |
| 连接词密度（每百句） | 21.2 | ≤22 |

**连接词种类少不是选词问题。** 它来自修辞槽位——引言末尾的假设句、讨论里的贡献句、独立的局限段。缺槽位的文章，换多少同义词都上不去。`references/protocol.md` §2 讲这件事。

换领域请先用自己的语料重算基线（`protocol.md` §1）。**两个不同的分句器会给同一篇文章两个不同的数。**

## 已知限制（照实说）

- **规则是启发式的，必有误报。** 基因符号长得像未定义缩写，样本量长得像数值冲突。停用表和频次过滤能压掉大部分，仍需人工判断。
- **基线只覆盖一个领域。** 临床试验、综述要自己重算。
- **它不判断科学对错。** 只说"这句和那句不一致"，不说"这句错了"。
- **最贵的错误仍然靠读。** 实测中最要命的三处——拆句留下的小写开头、与小节标题逐字重复的段落、连用六次的同一句式——全是人读出来的，没有一条是脚本报的。**脚本用来省注意力，不是替代阅读。**
